# Contributing

Lift is opinionated. The author decides the direction of the project and may refuse a pull request without explanation.

## Issues are welcome

If you have a problem with Lift, or an idea on how to improve it, please open an issue.
In it, provide a detailed explanation of your experience. If it's a bug, tell me how to reproduce it and what would be the expected behavior. If it's a recommendation, tell me how you came up with it.
If you want to suggest a solution, consider also attaching a carefully crafted prompt that I can run with an agent of my choice to implement it.
