# FormSimpleSelect

A select for a simple form.

```astro

import FormSimpleSelect from '@presets/(form)/(simple)/form-simple-select'
---

<label for="size">Size</label>
<FormSimpleSelect id="size" name="size">
	<option value="small">Small</option>
	<option value="large">Large</option>
</FormSimpleSelect>
```
