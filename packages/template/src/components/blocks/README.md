# @blocks

Blocks combine [primitives](../primitives/README.md) and other blocks into UI components.

A plain block contains markup and styles. An instance block adds a custom element and manager for interactive behavior. Instances can share logic through [behaviors](../../behaviors/README.md).

The CLI can create blocks from the project folder.

Edit the [block blueprints](_blueprints/README.md) to change what new blocks contain.
