# Icon

Display an SVG from `src/assets/(icon)`.

```astro
---
import Icon from '@primitives/icon'
---

<Icon name="icon-arrow-right" aria-hidden="true" />
```

Use the CLI to add an SVG or sync the icon registry after changing the folder by hand. Give meaningful icons an accessible label.
