# Intent of Text

Use `Text` to apply a design system’s typography to headings, paragraphs, and inline text. Choose `tag` for the HTML element, `variant` for the typography system, and `form` for a degree within that system. A degree can specify different values at different container widths.

Keep one variant per typography system. Use a design document or another agreed source of truth to define what each degree should look like.
